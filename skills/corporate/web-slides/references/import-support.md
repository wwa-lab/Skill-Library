# PPTX / POTX 本地导入范围

## 使用

已有 Python 3.9 或更新版本即可，不需要额外依赖。Windows 默认：

```powershell
py -3 scripts/ooxml.py "C:\公司材料\内部 培训.pptx" --out "C:\公司材料\导入 结果"
py -3 scripts/ooxml.py "C:\公司材料\公司 模板.potx" --out "C:\公司材料\品牌 配置" --brand-only
```

指定已存在的解释器可直接执行它；PowerShell 路径带空格时使用调用运算符：

```powershell
& "C:\公司工具\Python 3\python.exe" scripts/ooxml.py "C:\公司材料\模板.potx" --out "C:\公司材料\品牌" --brand-only
```

macOS / Linux 使用已检测到的 `python3` 或解释器绝对路径。代码不修改 PATH，不安装或升级软件，不访问网络，不执行 Office 宏。`.ppt` 明确拒绝，要求用户在 PowerPoint 另存为 `.pptx`。非标准 Strict OOXML 不保证兼容；没有可读取页面时应检查转换报告及模型，先用 PowerPoint 另存为普通 `.pptx`。

输出：`brand.json`、`conversion-report.json`（未转换对象可提取的文字保存在 `unconvertedContent`），内容导入另有 `deck.json`。不支持的图片原始字节保存到输出目录的 `assets/`，报告列出原始部件及文件路径。输入文件保持不变。品牌导入只生成配置；生成器使用配置后，浏览器无需 Python。

## 可复用品牌

提取首个主题中的颜色、标题及正文字体，以及全部母版、版式名称、版式类别和占位符清单。清单附对象类型、名称、文字、形状和 1600×900 归一化坐标；占位符坐标来自对象自身，缺省继承坐标标为 null，不能误当成已解析完成的完整布局。优先主题中的东亚字体，缺省采用 Microsoft YaHei。母版及版式里的 PNG/JPEG 图片进入 `logoCandidates`，不自动把任意图片当 Logo；确认后把选中候选的 `src` 写入 `brand.logo`。

`masters` / `layouts` 为可检查的源模板清单；本版不直接克隆任意 OOXML 母版。导出端依据规范化颜色、字体、Logo 创建统一母版与常用版式。源模板中的复杂背景、布局规则、占位符继承均需检查；报告明确标出此限制。多主题文件使用第一个主题并发出警告，源主题路径同时保留。

## 内容转换

| 对象 | 行为及限制 |
| --- | --- |
| 页面 | 按 `presentation.xml` 的关系顺序读取，包括隐藏页面；全部输出为可见页面。默认 1600×900，非 16:9 独立缩放横纵几何并报告可能变形。 |
| 文字 | 保留段落文本、换行和页面内顺序；合并富文本为单个文本对象。首个字体大小、粗体、颜色和首段对齐作为基础。字体沿用统一品牌，项目符号、混合格式、超链接、继承样式需人工复核。 |
| 图片 | PNG/JPEG 作为独立 data URL 图片。源裁切改为 contain 并报告，可在编辑器重新调整；非支持格式保留原文件并报告。外部图片仅报告，绝不下载。 |
| 形状 | 矩形、圆角矩形、椭圆、向右箭头、直线映射原生形状；复杂几何报告，能提取的文字仍保留。旋转、翻转、特效、渐变等报告规范化损失。 |
| 表格 | 1–12 行、1–8 列矩形表格，保持单元格文字，转为等宽等高品牌表格；合并单元格展开并报告。超出范围的对象明确报告未转换。 |
| 图表 | 单图区 bar / line / pie，最多 12 类别、4 系列（饼图 1 系列），使用 OOXML 缓存值，支持普通类别缓存和单层 `multiLvlStrCache`（多层分组类别报告不支持）。条形图与饼图非负；折线图可负。缺少或稀疏缓存、多图区、其他图种明确报告。源坐标轴、堆积、样式及工作簿公式不保留，导出使用模型数据重建可编辑图表。 |
| 讲稿 | 保留正文及普通讲稿文本框文本；日期、页码、页眉页脚、缩略图占位符不当作讲稿。讲稿图片和图形报告未转换。 |
| 动画/切换 | 静态终态，报告原动画/切换；需要关键步骤时须人工拆页。 |
| 分组、SmartArt、OLE、未知对象 | 报告所在源页面及对象，不宣称完整还原。分组整体不转换；导入前可在 PowerPoint 取消组合，SmartArt 可转为形状后再尝试。 |
| 母版及布局继承 | 分析清单；源页面依赖的每个母版/布局图形逐项报告未渲染。缺少自身坐标的占位符使用默认框并报告。 |

**每次导入必须先检查 `conversion-report.json`，再比较源页面与网页。** 所有文件都标记 `completeFidelity: false`，报告不能被当成“转换无损”的证明。完整源 `.pptx` 是尚未转换内容的保留依据。当前转换器为边界清晰的基础实现，不是 PowerPoint 渲染引擎。

## 安全与可验证范围

仅从 ZIP 定点读取，不调用 `extractall`。拒绝目录穿越、重复文件名、加密成员、XML DTD/实体声明；限制最多 4096 个部件、单部件 32 MiB、总解压尺寸 128 MiB 和最多 200 页。关系路径不能逃出包根，外部关系不请求网络。图片仅根据 PNG/JPEG 文件头识别，浏览器负责解码；不支持的媒体不会作为 HTML 或脚本执行。

自动化测试使用合成 PPTX/POTX：页面关系乱序、中文讲稿、嵌入 PNG、母版 Logo 候选、主题字体、表格、缓存图表、无法识别图片原件、中文及空格路径、外部关系、越界 ZIP 与 XML DTD。当前 macOS 标准 Python 实测不代表 Windows `py -3`、公司浏览器或实际 PowerPoint 已验收；这些应按交付验收清单另行标记。

```text
python3 -m unittest discover -s tests -p "test_ooxml*.py"
```
