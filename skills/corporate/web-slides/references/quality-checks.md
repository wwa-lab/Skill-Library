# 交付验收清单

每次交付记录文件、日期、平台、浏览器、测试方法和未验证项目。自动化结构测试只证明结构与数据，不能代替 PowerPoint 实机交互。

## 本地生成与网页

- 模型通过 Python 和浏览器校验；不含外部图片/脚本/CSS/字体引用，单文件在断网状态从 `file://` 打开。
- 至少检查 1280×720、1366×768、1920×1080 桌面及 1024×768 投影；画布始终 16:9 等比缩放，中文无裁断/溢出。检查图表标签相互遮挡、表格和页脚。
- 展示/编辑模式明确；键盘、目录、讲稿、全屏、系统与手动减少动态工作。编辑输入框不因箭头键翻页。
- 实际修改标题、正文、讲稿、图片、字号/强调色/对齐；改裁切及横纵位置；增删/复制/拖动排序；撤销重做可恢复内容。上传图片读取完成前不导出旧图。
- 下载 HTML 到中文及空格路径；关掉原页，离线重开，比较模型内容和顺序；再编辑、再保存并重开。缓存清空后仍完整。
- 转换报告逐页检查，无法转换对象不能只在控制台留下不可见信息；报告及原文件随可审查交付保留。

## PPTX/POTX 自动结构检查

- 浏览器从**修改后的模型**导出；对比页数、页序、所有纯文本及讲稿。
- 文字为 `p:sp` / `a:t`，图片为 `p:pic`，流程是原生几何，表格为 `a:tbl`，图表为 `c:chart` 且含独立工作簿。
- notesSlides 数量与页数一致，完整讲稿匹配；内部关系指向包中存在的部件，无远程图片引用。
- 原生主题包含品牌颜色和东亚字体，布局含 title/body 占位符与品牌背景/Logo/页脚。
- 用导出组件新增一页 CORPORATE_CONTENT，验证新页通过布局关系继承主题。此操作是 OOXML 模拟，不称为 PowerPoint UI 验收。
- POTX 主内容类型为 template；讲稿和版式未丢失。
