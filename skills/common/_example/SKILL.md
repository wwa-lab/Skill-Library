# Common Example Skill

Use this example as a small reference when creating a new skill in this repository.

## Workflow

1. Confirm the user request matches the skill description.
2. Read only the references needed for the task.
3. Follow the workflow in the skill body.
4. Run any verification steps that are relevant to the task.
5. Summarize what changed and how it was checked.

## References

Read `references/example-reference.md` only when you need a concrete example of how to link supporting material from a skill.
